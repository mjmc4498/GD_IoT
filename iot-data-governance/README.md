# Gobierno de Datos para IoT (GD_IoT)

Este proyecto es un sistema integral que combina Gobierno de Datos con tecnologías IoT, diseñado para garantizar la calidad, seguridad y trazabilidad de los datos generados por sensores inteligentes en tiempo real.

## Despliegue

El sitio está desplegado en GitHub Pages y se puede acceder a él a través del siguiente enlace:

[https://mjmc4498.github.io/GD_IoT/](https://mjmc4498.github.io/GD_IoT/)

## Instalación

Para ejecutar este proyecto localmente, sigue estos pasos:

1.  Clona el repositorio:
    ```bash
    git clone https://github.com/mjmc4498/GD_IoT.git
    ```
2.  Navega al directorio del frontend:
    ```bash
    cd GD_IoT/iot-data-governance/frontend
    ```
3.  Abre el archivo `index.html` en tu navegador.

## Manual del Sistema y Uso

La interfaz web te permite interactuar con el sistema de Gobierno de Datos IoT. A continuación, se describen las principales funcionalidades:

*   **Dispositivos**: En esta sección, podrás ver una lista de todos los dispositivos IoT conectados al sistema, así como su estado en tiempo real.
*   **Reglas de Gobernanza**: Aquí podrás definir y gestionar las reglas de gobernanza que se aplicarán a los datos generados por los dispositivos.
*   **Alertas**: En esta sección, podrás ver las alertas generadas por el sistema cuando se detecta una anomalía en los datos.
